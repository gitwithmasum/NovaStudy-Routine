# Python CP Roadmap inside DSA & CP

The existing 14 DSA modules remain unchanged. Ten new Codeforces-oriented Python CP phases appear immediately after them inside **Learning → Skills & Modules → DSA & CP**.

## Phase 1: Python CP Basics (Must)
- Fast I/O: input() and sys.stdin.buffer
- Loops and conditionals
- Lists and array traversal
- Strings and characters
- Dictionaries and frequency maps
- Sets and unique values
- Big-O time and space complexity
- collections, itertools and functools
- bisect, heapq and math

## Phase 2: Core Problem Solving (Must)
- Implementation and simulation
- Basic mathematics
- Brute-force enumeration
- Sorting and custom keys
- Frequency counting and counting arrays

## Phase 3: Algorithmic Thinking (Must)
- Greedy algorithms
- Constructive algorithms
- Prefix sums
- Two pointers

## Phase 4: Search Techniques (High)
- Binary search
- Binary search on answer
- Sliding window

## Phase 5: Mathematics (High)
- GCD and Euclidean algorithm
- LCM and divisibility
- Prime numbers and factorization
- Sieve of Eratosthenes
- Modular arithmetic
- Combinatorics

## Phase 6: Data Structures (High)
- Stack
- Queue
- Deque
- Heap (heapq)
- Hash map
- Priority queue

## Phase 7: Dynamic Programming (High)
- Memoization
- 1D DP
- 2D DP
- 0/1 Knapsack
- Longest Increasing Subsequence (LIS)
- Grid DP

## Phase 8: Graph Algorithms (High)
- BFS
- DFS
- Shortest path algorithms
- Connected components
- Disjoint Set Union (DSU)

## Phase 9: Advanced Topics (Later)
- Trees and traversals
- Bitmask DP
- Fenwick Tree
- Segment Tree
- Sparse Table

## Phase 10: Expert Topics (Later)
- Advanced graph algorithms
- String algorithms (KMP, Z-function)
- Digit DP
- Advanced combinatorics

Each phase has an independent roadmap progress dropdown and individual topic completion controls.
