06 / Technical requirements

Lightweight to access. Easy to get started.

Technical notes

NovaStudy is delivered as a web application with installable PWA support. Some app-shell resources can be cached for offline access after an online visit. Account, cloud backup and sync features require their configured online services. Browser storage is origin/profile-specific; export backups before clearing site data or moving devices.

The app does not require a desktop installer. It does not provide a native APK or IPA through this landing page.

08 / FAQ & support

Questions, answered.

Can I try NovaStudy before purchasing?

Yes. Open the live demo and explore the currently available app features before requesting a paid license.

Does NovaStudy work offline?

The installable PWA can cache its app shell after a successful online visit. Features that need authentication, cloud services or online resources still require an internet connection.

Will my data sync automatically across devices?

Do not assume that all data syncs automatically. Browser-local data is origin- and profile-specific. Use the backup and restore tools and review the app's cloud/sync documentation for the supported workflow.

Can I install NovaStudy on my phone?

On supported browsers, use the browser's Install app or Add to Home Screen option. This is a PWA installation, not an APK or IPA download.

How do I report a bug or request help?

Open a GitHub issue with the steps to reproduce the problem. Avoid including passwords, access tokens or private academic records.

How do paid licenses and refunds work?

Paid checkout, final license terms and refund policy are being prepared. They will be published before paid orders are accepted.
